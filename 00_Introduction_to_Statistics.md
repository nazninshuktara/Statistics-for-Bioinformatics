# Introduction to Statistics

## What is Statistics?

Statistics is the science of collecting, organizing, analyzing, interpreting, and communicating data.

In bioinformatics, we work with different types of biological data such as gene expression, sequencing data, clinical data, and other quantitative measurements. These data often contain variation and noise. Statistics helps us understand this variation and identify patterns, compare groups, test hypotheses, and determine whether an observed pattern or difference is meaningful.

## Why Statistics is Important in Bioinformatics

Bioinformatics data can contain biological variation, technical variation, and random noise. Statistical methods help us distinguish meaningful biological patterns from variation that may occur by chance.

Statistics is commonly used to:

* Summarize biological data
* Measure variability
* Understand data distributions
* Compare biological groups
* Test scientific hypotheses
* Measure relationships between variables
* Quantify uncertainty
* Evaluate statistical significance
* Support biological interpretation

## Statistics in a Bioinformatics Workflow

A simplified workflow is:

```text
Biological Question
        ↓
Data Collection
        ↓
Data Preparation
        ↓
Exploratory Data Analysis
        ↓
Statistical Analysis
        ↓
Interpretation
        ↓
Biological Conclusion
```

Statistics can be applied at different stages of this workflow, from exploring the data to evaluating evidence for biological findings.

## Statistics and R

R is widely used for statistical analysis and visualization in bioinformatics.

This repository uses R to practice statistical concepts with example data and understand how statistical methods are applied to biological data.

The goal is not only to learn R functions, but also to understand:

> **What method should be used, why should it be used, and how should the result be interpreted?**

## Topics Covered

This repository will cover statistical concepts commonly used in bioinformatics, including:

* Descriptive statistics
* Probability and hypothesis testing
* p-values and statistical significance
* t-test
* ANOVA
* Multiple testing and FDR
* Correlation
* Linear regression
* Categorical data analysis
* Chi-square test
* Fisher's exact test
* Odds ratio
* Data transformation and normalization
* Experimental design
* Replicates, confounding, and batch effects

## Learning Approach

Each topic is documented in a separate R script.
The scripts contain:

* Short explanations
* Example data
* R code
* Statistical calculations
* Basic interpretation

The goal of this repository is to build a practical foundation in statistics that can be applied to bioinformatics and biological data analysis.

The repository will be updated as new statistical concepts are learned and practiced.
